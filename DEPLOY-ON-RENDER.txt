SAGUAVOW CHARCUTERIE CO. — RENDER DEPLOYMENT

IMPORTANT: Upload the FILES inside this folder to the ROOT of your GitHub repository.
When you open your GitHub repository, you should immediately see:

package.json
server.js
render.yaml
public/
README.md

Do NOT put all of these inside another saguavow-charcuterie-site folder.

EASIEST RENDER SETUP
1. Put these files at the root of a GitHub repository.
2. Sign in to Render.
3. Choose New > Blueprint.
4. Connect the GitHub repository.
5. Render will read render.yaml.
6. Add your STRIPE_SECRET_KEY when Render asks for it.
7. PUBLIC_URL can initially be left blank. The server will use the Render URL automatically.
8. Deploy.

Manual Web Service setup also works:
Build Command: npm install
Start Command: npm start

Once deployed, test:
https://YOUR-RENDER-NAME.onrender.com/health

It should show a JSON message with "ok": true.

PAYMENT TESTING
Use a Stripe TEST secret key first (starts with sk_test_).
Never place secret keys in public/index.html or GitHub.

One-time Classic promo:
Add CLASSIC_PROMO_CODE=YOUR_PRIVATE_CODE in Render -> Environment.
Do not put the real code in GitHub.
